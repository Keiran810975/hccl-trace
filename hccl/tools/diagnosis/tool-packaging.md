2026-10-29，nf。使用方法见[工具说明](../../../文档/诊断工具使用说明.md)。

## 功能

- `hccl-diag analyze` 整合发现、调用绑定、精确合并、依赖构建、检测和源头候选溯源。
- Baseline/Rolling 统一输出，仅发布 execution.html、root_causes.json、propagation.html。
- 默认删除本次临时分析，不删除原始输入；拒绝覆盖结果，支持独立调试目录。
- 公开 SDK 提供真实通信成员及 iteration/group/call-site/occurrence，不固定机器数、卡数
  或全局 Rank 连续编号；完成边界由用户原有训练逻辑提供，不隐式同步设备。
- HOST API 关联仅接受相同线程和相同起止时间的 launch 证据；长 HOST 任务编号回绕
  在临时空间复用权威 batch 导出，不按最近时间/序号配对。
- 执行图高亮已有候选与路径，Host 准备区间单独显示，Record 只作设备锚点，不补伪造边。
