# 单簇 Top1 修复与评分回放

## 当前行为

**只选评分最高的一个候选簇，簇内所有候选平行展示。**
不再将“候选平行”解释为“所有通过条件的簇全部输出”。

显式入口为 `--source-policy cluster-top1`；`parallel` 现在是此入口的兼容别名，
不再调用此前的全保留策略。`legacy` 默认值、旧 `dual`/`dual-v2` 和服务器活动快照不变。
稳定入口保留原dual-v2评分与选择，不因这次修复而丢失原有成功案例。
此前全保留试验的输入、代码备份、失败结果和三报告仍保留，不原地重写。

```bash
hccl-diag analyze --capture /data/capture --mode rolling \
  --source-policy cluster-top1 --selected-iteration-view --keep-debug \
  --output /data/top1-report
```

## 评分实验（未替换稳定入口）

另提供显式 `--source-policy cluster-top1-time` 研究入口。它不是`cluster-top1`的默认评分，
因为逐例评测发现了已知回退，不能仅看汇总数字就发布替换。

1. 复用 `local_slow_clusters.build_clusters` 的原始依赖簇，不按整次调用或共同语义重新聚类。
   原有控制路径、正常资源分隔、自适应局部性、历史身份、1.5倍/3MAD预选全部保留。
2. 簇排名改用本地观测执行增量，降低极短任务高倍数抖动对簇评分的影响。
   对任务计算 `duration - preceding_five_mean`，除以 `1 + past_alarm_fraction`，
   同一物理 stream 内求和，簇分取各 stream 中最大值。
   不把并行 stream 的耗时相加，不把评分称为全局关键路径收益或训练损失。
3. 簇排名不再使用原来的相对倍数截顶或邻近慢任务加分。
   前五轮均值/MAD和任务预选门槛没有改变，历史报警折扣仍只读取过去事实。
4. Host 仍须通过原有准备/API/唯一 Notify 与慢 Wait 支持校验；以准备增长及观测 Wait
   重叠的较小值作为有界评分，与资源簇竞争一个位置。Host 区间不是设备任务。
5. 同分按稳定簇ID确定；公开候选按时间/稳定ID展示，编号不是任务优先级。
   完整簇评分、其他簇及落选事实保存在独立审计中，不变成公开候选。

公式仅是排序启发式，不证明物理故障位置。相同 stream 的工作区间若重叠，则该簇不以
串行时间和评分，明确标记不可如此排序，不补造时间。

## 回放结果

对上一轮开始时已归档的12例固定样本，重新读取并逐项核对原任务比较和依赖边。
**每例重建出的全部簇ID均与原 dual-v2 提案完全一致**；原获胜簇成员也逐项一致。
因此以下差异来自评分，不是扩大簇范围或改任务身份。
选择结果先封存，再独立按原始同Node/Rank正时间重叠评测，不改注入窗口。

| 样本 | 原 dual-v2 命中候选/全部候选 | 新Top1命中候选/全部候选 | 原任一命中 | 新任一命中 |
|---|---:|---:|---:|---:|
| SDMA竞争 | 3/8 | 8/19 | 1/3 | 1/3 |
| 通信竞争 | 0/16 | 5/22 | 0/4 | 1/4 |
| Host调用前迟到 | 3/3区间 | 3/3区间 | 3/3 | 3/3 |
| RoCE限速样本内执行任务 | 0/6 | 0/13 | 0/2 | 0/2 |

上表是时间评分实验，不是稳定入口的新精度。实验每例1至8候选；稳定入口保留原选择，
本快照为1至6候选/例，均不再全保留数百任务。
实验中通信竞争1010从0/4变为5/5，SDMA1009从0/2变为8/8，Host三例没有回退；
但SDMA1005从原3/3回退为0/6。**这个回退不能被SDMA总组命中率仍为1/3掩盖。**
因此时间评分仅单列研究，稳定Top1继续保留原评分。RoCE没有解决，不称多机定位全面验收通过。
上述是已知样本离线开发回放，不是独立盲测、一般准确率或正常误报率校准。
任务和Host区间不合算候选精度。

未排除任何实验组。未命中例仍保留；审计记录注入窗口内最好簇的排名及分数，
但不使用这些信息生成候选。比如1005的新获胜簇与窗口内最好簇分数接近，
不能单凭漏诊就断言整组数据无效。更大或相近的非注入位置波动仍可能赢得Top1。

本样本快照属于原19例低日志批次：12完整、1012技术失败、6未运行；旧INFO首例901单列。
这些是快照分母，不是实时队列状态。本轮没有启动训练、重复注入、改采集包或改活动快照。
