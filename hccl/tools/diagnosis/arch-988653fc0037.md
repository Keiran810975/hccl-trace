## 4. Notify 命名空间调查

### SEM-007

- `notify_id=(user_rank << 32) | offset_low32` 是可用的物理 Notify 资源身份。
- record 与对应 wait 通常位于不同 device；旧
  `(node, device, notify_id)` 分组会错误拆开同步两端。
- 去掉 device 后，Notify 资源仍会跨 step、graph launch 和 collective invocation 复用。
- `connection_id` 是 profiler 本地关联范围，不是同步 pair identity。
- 后续精确关系由活动任务 DEP-005～DEP-010 实现，禁止再以数值巧合或最近时间提升为
  exact/observed。
