## 2. 覆盖口径

“全部覆盖”指：910B、910C 单机 AllReduce 选择器中每个**可达算法语义族**都有明确状态；不要求为每个 executor wrapper、数据阈值或 datatype 重复实现相同语义。

覆盖分为两层：

1. **模板语义覆盖**：不同通信步骤、peer 关系或执行粒度必须有独立 semantic contract。
2. **选择器覆盖**：证明特定 device/条件选择到了预期 executor 和底层模板。

覆盖主键为：

```text
device + selector condition + executor + template/algorithm + phase
```

同一模板的 loop/chunk wrapper 可以共享生产端插桩，但至少要有选择器 fixture；910B 和 910C 即使共享模板，也要分别提供设备测试 ID，因为 transport lowering 和物理 task kind 可能不同。

当前不覆盖 `COMM_LEVEL1`/`COMM_LEVEL2`，也不为其增加显式 context。Pipeline、NB、AHC 及
hierarchical NHR 等跨机阶段保持延期；但 `AllReduceComm` 在单机 combine plane 上显式选择
NHR/NHR-Oneshot 的条件路径归入 COV-012，不视为 Level1 多机覆盖。

### 2.1 单机 NHR 边界

正常默认单机不会选择有实际跨 rank 通信的 NHR：

- `GetDefaultAlgoLevel1V1(moduleNum=1)` 明确选择 Ring；910C 的 HD→NHR 重定向不会触发；
- 910B op-base auto selection 在 `isSingleMeshAggregation_` 为 true 时直接返回，不重选 Level1；
- Mesh/Ring hierarchical executor 即使保留 Level1=NHR 分支，单机 Level1 domain 通常退化为
  rank size 1，不构成需要单独覆盖的 NHR 通信。

但单机 NHR 不是绝对不可达：`SetAlgoLevel1()` 接受显式 NHR 配置，不因 `moduleNum=1` 拒绝；
当 Level0 NULL/common 或特殊 fallback 使 selector 进入 `AllReduceComm` 时，该 executor 会在
`COMM_COMBINE`（910B）或 `COMM_COMBINE_ORDER`（910C）上运行 `TEMPLATE_ALL_REDUCE_NHR`/
`TEMPLATE_ALL_REDUCE_NHR_ONESHOT`。源码 ST 分别证明了 AllReduce 接受
`HCCL_ALGO=level0:ring;level1:NHR`，以及单机 common topology 可以选择 `AllReduceComm`，但尚无
同时满足两者的现成用例；环境变量本身不能保证进入 `AllReduceComm`。`feat-NHR@3acb7df` 已实现
候选生产打点，仍需在目标设备上证明最终选路和物理 task 对齐。这是一条单机打平算法路径，不并入
多机 Level1 完整覆盖声明。

## 9. 实施优先级

### P0：Host/FFTS 主路径

1. 910B standard Ring（COV-002）。
2. 910B normal/atomic Mesh（COV-003）。
3. 910B/910C small-count：HD、Doubling、Reduce-Bcast、Local Reduce-Bcast（COV-009）。
4. 910C Single/Fast Double/Zero-copy Ring（COV-011）。
5. Single rank（COV-012）。

### P0：独立 AIV 轨道

AIV 是两种目标设备的真实选择路径，不作为可选长尾；但它的可观测粒度与 Host/FFTS 不同，由 COV-007 单独设计和验收。

### P1：条件路径

1. 910B deterministic、Order Preserved、Oneshot/Chunk（COV-010）。
2. `AllReduceComm` 单机 fallback 及显式 NHR/NHR-Oneshot 设备验证（COV-005/COV-012）。
3. workflow、buffer placement、datatype/reduce-op 的等价类补测。

### 延期

Level1/Level2 hierarchical NHR、NB、AHC、跨机 pipeline 和 RDMA/RoCE。实现多机时再定义显式
context、rank 域和 protocol sequence；单机 combine-plane NHR 不在此延期项内。

- 记录 `device_product`、运行时 `DevType`、device/rank 数；
